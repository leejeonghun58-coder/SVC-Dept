# SSDA 구현 계획 순서

승인된 통합 설계를 다음 세 계획으로 나누어 실행한다.

1. `2026-09-29-ssda-foundation-ingestion.md`
   - 프로젝트 기반, 초대 전용 인증, Supabase 스키마·RLS, 대용량 업로드, 검증, 버전 승인·복구
2. `2026-09-29-ssda-analytics-ui.md`
   - 지표 규칙, 출고 대시보드, 품목 분석, 고객명·DV 상세, 고객 매핑과 품질 작업 목록
3. `2026-09-29-ssda-reports-release.md`
   - Excel/PDF 보고서, 비동기 출력, 정합성·보안·성능 검증, GitHub·Supabase·Vercel 배포

각 계획은 앞선 계획의 공개 인터페이스를 사용하며, 계획별 전체 테스트가 통과한 뒤 다음 계획으로 이동한다.

구현 전 필수 업무 확인:

- 출고 금액·총비용과 주요 분류 필드의 정확한 원본 열 매핑
- 음수 수량의 최종 업무 규칙
- 두 번째 출고 파일 피벗 캐시의 운영 적재원 사용 승인
- 회사 자료의 외부 클라우드 저장 및 집 PC 처리 승인
- 실제 Vercel·Supabase 요금제와 용량 검토
